# TROUVE MARIN MICHEL

Offline operations control for audit logs, task management, resource allocation, and supply ordering.

## Project Contents

- `lib/` contains the Flutter Android app source.
- `android/` contains the Android platform project and release signing configuration.
- `web/` contains a standalone static website.
- `docs/` contains Play Store text assets, graphics, and screenshots.

The app stores operation records and preferences locally on the device. It does not use Android permissions, account registration, cloud sync, analytics, ads, or network services.
